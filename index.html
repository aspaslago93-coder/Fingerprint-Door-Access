Tentang Sistem

Arduino Fingerprint Door Access System merupakan simulasi sistem keamanan pintu menggunakan teknologi autentikasi sidik jari.

Sistem ini menggunakan Arduino Uno dan sensor fingerprint FPM10A untuk melakukan proses identifikasi pengguna.

Alur Kerja Sistem

  1. Pengguna memilih sidik jari.
  2. Sensor melakukan proses pemindaian.
  3. Sistem memverifikasi sidik jari.
  4. Jika valid, pintu terbuka.
  5. Jika tidak valid, akses ditolak.
  6. Sistem mencatat aktivitas ke dalam log.
